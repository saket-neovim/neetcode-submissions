# Python Data Structures and Algorithms Practice

A collection of Python submissions from [NeetCode](https://neetcode.io), retained as coding-interview practice alongside the infrastructure repositories in this profile.

## Organization

Submissions live under [Data Structures & Algorithms](Data%20Structures%20%26%20Algorithms/), grouped by problem slug. Multiple `submission-*.py` files preserve different attempts or revisions; a higher suffix does not by itself establish correctness or efficiency.

## Reading and checking a solution

Use Python 3 and open an individual problem directory. Many submissions expose a `Solution` method and rely on the platform's input harness or provided types rather than a standalone command-line interface.

A syntax-only check, using an existing example path:

```bash
python3 -m py_compile 'Data Structures & Algorithms/anagram-groups/submission-0.py'
```

Compilation does not verify algorithm correctness, accepted status, complexity, or edge cases. To evaluate an attempt, use the original problem's specification and harness, and check empty inputs, duplicates, boundary sizes, and expected time/space cost.
